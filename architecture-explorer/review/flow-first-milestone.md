# Four-page flow-first learning review

Scope: the four flagship lessons in Korean and English. The other 73 lesson bodies,
production code, migrations, contracts and curated verification evidence are unchanged
by this milestone. This revision is a local review build, not a new deployment.

## Reading surface

- One shared map places Google Drive / Notion / Files visibly outside Knowledge OS.
- Remember and find are branches through the same system. Experience-scope labels
  distinguish a target conversation from implemented boundaries, partial paths and
  intentional deferrals. They do not replace VERIFIED / IMPLEMENTED / KNOWN ISSUE /
  DEFERRED verification records.
- Six user jobs reveal their bounded flow. The map strip shows current position;
  hash navigation supports back/forward and language changes. Returning to the map
  retains the selected stage.
- Each new visual section has one question, one diagram and one short paragraph.
  Examples/reasons/comprehension checks are under “Why does it work this way?”.
  Prior long-form prose and repository references remain in the technical layer.
- Twenty inline glossary entries support hover, focus, tap, close and Escape.
  Human labels precede technical names. Term introduction metadata and validation
  cover only the four approved beginner lessons, not the unchanged reference pages.

## One-minute novice review rubric

The default Start Here screen makes these answers available without opening code:

| Question | Expected explanation |
| --- | --- |
| Where are my originals? | In Drive, Notion or Files, outside Knowledge OS. |
| What does Knowledge OS add? | Links supporting material and reviewed statements so they can be found and checked. |
| What does remembering involve? | Prepare evidence, submit a candidate, review, accept; one-message automation is a target. |
| What does finding involve? | Check access, retrieve supporting material/connections, return material for Claude/GPT to answer. |
| Why not trust AI immediately? | AI can infer more than the original says; candidates require evidence and review. |

This is a design audit, not an observed usability study. A real novice's ability to
explain this within 60 seconds remains the user's review criterion. Review only these
four pages before authorizing any expansion to the remaining 73.
