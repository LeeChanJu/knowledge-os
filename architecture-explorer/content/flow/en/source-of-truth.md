## Where do I go to edit the note?

```diagram
☁️ Drive / Notion / Files → create and edit originals
↓ Read permitted material
Knowledge OS → connects past evidence and reviewed statements
```

Managing an original and helping interpret it are different jobs. Edit a sentence in the SAP AI study note at its original location. Having a record in Knowledge OS does not grant permission to edit that source.

## If the original changes, how do I check yesterday's answer?

```diagram
Yesterday: “Reviewing both technologies” → preserved evidence
Today: “Review stopped” → new evidence
Yesterday's answer → return to yesterday's supporting material
```

Keeping only today's original can lose the reason behind yesterday's answer. We distinguish [the document at that time](term:version). Keeping an earlier record does not grant permanent permission to read it today.

## Compare the two responsibilities

| Question | Original system | Knowledge OS |
| --- | --- | --- |
| Where do I edit the note? | Owns the original editing location | Does not replace it |
| Which sentence supported the answer? | Today's file may be insufficient | Links to evidence as it was |
| May AI change an outside document? | Separate write permission required | Separates request, review and execution |

The authoritative home of an original is called the Source of Truth. Connecting context around originals is the System of Context role. Understand the two responsibilities before attaching these names.

## The “I can read it, so I can write it” mistake

[A request to change an outside system](term:action) is different from search. A bounded Notion execution path exists, but requires separate policy, human approval and execution authority. MCP do not automatically approve or execute it.

## Explain it in your own words

```check
You found the note through Knowledge OS. Why does that not mean you can edit the original here?
---
Finding material and being authorized to change its source are different. The source system owns editing, and outside changes require separate approval and an authorized executor.
```

```check
The original changed today, but you must explain yesterday's answer. What is lost if only today's file is kept?
---
The exact sentence and state used yesterday may be lost. Distinguishable versions and passages let you trace the earlier answer.
```

```check
Can someone who lost access keep reading an earlier version just because it is preserved?
---
No. Preserving the identity of historical evidence is separate from allowing access today. Current source-based read permissions are checked.
```
