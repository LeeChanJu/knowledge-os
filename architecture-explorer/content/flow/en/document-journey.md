## How do we answer “Where did this come from?”

```diagram
💡 A statement used in the answer
↑ ✂️ A supporting passage
↑ 📸 The document at that time
↑ 📄 SAP AI study note
↑ ☁️ Original Drive document
```

Current permissions determine whether the material can be read. Following the links reveals which material, in which state, supported the answer. These links enable [tracing back to the source](term:provenance); the inspectable material is [supporting evidence](term:evidence).

## Why distinguish parts of a single note?

```diagram
📄 The same ongoing note → a record linking to the original
📸 First read / after an edit → distinct versions
✂️ The part needed for an answer → a separately citable piece
```

[The document record](term:document) identifies which note; [the version](term:version) identifies which state. [A supporting passage](term:chunk) identifies which part to cite. Depending on how text is split, a piece need not be exactly one paragraph.

## Do different questions need different ways of finding material?

```diagram
“Notes containing A2A” → find matching words
“What I studied about communicating programs” → find similar meaning
“Technologies connected to A2A” → follow recorded connections
```

Finding a name differs from asking about a connection. Word search and bounded connection reads exist; automatic production population for meaning search is intentionally deferred. This is not a claim that all three paths form a finished automatic product.

<!-- WHY -->
## Where are we on the map?

We are after the original source and before proposing knowledge or searching. Reading a document and preserving pieces does not approve its contents. Knowledge requiring review must still enter as a candidate.

## Why use several search signals?

[Matching words](term:fulltext) helps with exact names; [finding similar meaning](term:vector) helps when wording differs. The latter needs [numbers for comparing meaning](term:embedding). Similarity is not proof that two technologies have a usage relationship.

[Finding material](term:retrieval) is distinct from writing an answer. If no supported connection exists, shared words are not enough to assert one. Time and correction behavior still have unresolved verification findings.

```check
What can we answer more precisely by citing a passage rather than an entire note?
---
“Where exactly is that stated?” A specific part of an identified version lets a reviewer inspect the actual support, rather than search an entire changing document.
```

```check
A differently worded passage was found. Does that establish a true relationship between two technologies?
---

```

```check
Immediately after importing a document, may we use every sentence as accepted knowledge without review?
---
No. Importing preserves evidence. Preparing a candidate and reviewing what the evidence supports are separate responsibilities.
```
