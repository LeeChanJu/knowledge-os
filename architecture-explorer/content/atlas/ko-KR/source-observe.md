커넥터는 허용된 원문과 권한·버전을 관찰합니다. 예를 들어 Drive 폴더에서 이 메모를 읽어 변경 목록을 만듭니다. 조회 권한과 외부 수정 권한은 다릅니다.

### 왜 이 책임이 필요한가

삭제를 선언하기 전에 전체 목록을 완성합니다. 그래프 커밋 성공 후에만 로컬 체크포인트를 기록합니다.

### 입력과 출력

입력: 제공자 목록, 원본 권한, 이전 연결기 체크포인트.

출력: 결정적인 UPSERT/TOMBSTONE manifest와 다음 체크포인트 후보.

### 무엇을 보존하는가

- 어댑터 로컬 체크포인트 파일. 정식 의미 지식은 소유하지 않습니다.
- 재시도는 같은 의미 상태를 재현해야 합니다. 제공자 실패를 성공한 빈 목록으로 해석하면 안 됩니다.

### 예시를 따라가 보기

폴더 목록을 읽다 오류가 났다고 보이지 않은 메모를 삭제 처리하면 안 됩니다. 전체 목록을 확인한 뒤 변경을 만들고, 커밋 후 체크포인트를 기록합니다.

### 혼동하지 말아야 할 점

재시도는 같은 의미 상태를 재현해야 합니다. 제공자 실패를 성공한 빈 목록으로 해석하면 안 됩니다.
