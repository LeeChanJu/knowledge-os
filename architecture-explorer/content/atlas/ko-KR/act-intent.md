## 결정과 실제 변경은 같은가요?

```diagram
“이렇게 하기로 했다” → 결정 기록
“원본에 반영해달라” → 별도 변경 요청
요청만으로 실행되지 않음
```

무엇을 하기로 결정한 것과 실제 외부 시스템을 바꾸는 것은 다릅니다. 실행 요청에는 대상과 수행하려는 작업을 명시해야 합니다. MCP를 통해 요청했다고 승인 권한이 생기지는 않습니다.

<!-- DEPTH -->

### 왜 이 책임이 필요한가

직접 데이터베이스 권한 없이 에이전트가 맥락을 사용하고 검토를 요청하게 합니다.

### 입력과 출력

입력: 제한된 MCP 인자와 호스트 소유 작업공간·주체.

출력: 지식 서비스 결과 또는 관리 대상 요청 접수.

### 무엇을 보존하는가

- 호스트 어댑터 설정만 소유하며 별도 지식 저장소는 없습니다.
- 직접 Cypher·수집·승인·Action 실행·외부 변경 도구는 없습니다. 관리 대상 요청을 제출할 수 있으므로 MCP 전체가 읽기 전용은 아닙니다.

### 예시를 따라가 보기

Claude/GPT가 메모를 물으면 MCP가 정해진 읽기 요청을 전달합니다. 연결됐다는 이유로 임의 Cypher, 지식 승인, 외부 실행 권한을 얻지 않습니다.

### 혼동하지 말아야 할 점

직접 Cypher·수집·승인·Action 실행·외부 변경 도구는 없습니다. 관리 대상 요청을 제출할 수 있으므로 MCP 전체가 읽기 전용은 아닙니다.
