문서 식별자는 변경 전후의 메모를 같은 문서로 묶습니다. 제목이 같다는 이유만으로 서로 다른 시스템의 문서를 합치지는 않습니다.

<!-- DEPTH -->

### 왜 이 책임이 필요한가

과거 근거를 덮어쓰지 않고 수명주기와 CURRENT_VERSION 기준점을 제공합니다.

### 입력과 출력

입력: Source 식별과 외부 문서 ID.

출력: 안정된 문서 ID, 현재 버전 포인터, 버전 이력.

### 무엇을 보존하는가

- 문서 식별, 활성·삭제 상태, 현재 버전 관계.
- 식별은 작업공간·원본 범위입니다. 삭제 관찰은 버전 이력을 남기며 직접 갱신에는 현재 버전 전제조건이 필요합니다.

### 예시를 따라가 보기

메모의 제목이 바뀌어도 같은 원본 문서의 관찰로 이어져야 합니다. 문서 식별과 그때의 내용 식별을 나누는 이유입니다.

### 혼동하지 말아야 할 점

식별은 작업공간·원본 범위입니다. 삭제 관찰은 버전 이력을 남기며 직접 갱신에는 현재 버전 전제조건이 필요합니다.
