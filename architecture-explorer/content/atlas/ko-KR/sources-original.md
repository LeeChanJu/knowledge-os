## 원본은 어디 있고 누가 읽을 수 있나요?

```diagram
근거 문단 → 그때의 문서
↓ 원본 문서의 연결 기록
☁️ Drive / Notion / Files · 원본은 여기
```

원본은 Knowledge OS 바깥의 시스템에 남습니다. 과거 근거를 추적할 수 있어도 현재 읽기 권한이 없으면 자료를 돌려주지 않습니다. 기록 보존이 영구 접근권은 아닙니다.

<!-- DEPTH -->

### 왜 이 책임이 필요한가

원본 식별과 체크포인트를 결합해 재시도와 원본 목록이 같은 모음을 가리키게 합니다.

### 입력과 출력

입력: 작업공간, 원본 유형, 불투명 외부 ID, 연결기 ID.

출력: 안정된 Source 식별과 권한 있는 목록·체크포인트 요약.

### 무엇을 보존하는가

- Source 노드, 연결기 결합, 커밋된 동기화 커서.
- 다른 연결기가 소유권을 조용히 가져갈 수 없습니다. 항목 수집만으로 완료 실행의 체크포인트를 전진시키지 않습니다.

### 예시를 따라가 보기

같은 제목의 메모가 두 연결에 있을 때 제목만으로 합치지 않습니다. 어느 작업공간·원본·연결기에서 관찰했는지가 식별의 일부입니다.

### 혼동하지 말아야 할 점

다른 연결기가 소유권을 조용히 가져갈 수 없습니다. 항목 수집만으로 완료 실행의 체크포인트를 전진시키지 않습니다.
