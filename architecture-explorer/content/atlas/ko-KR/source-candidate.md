### 왜 이 책임이 필요한가

추출 맥락을 찾을 수 있게 하면서 모든 제안 지식을 검토 절차로 보냅니다.

### 입력과 출력

입력: 권한 있는 근거 묶음, 온톨로지 버전, 프롬프트 버전·체크섬.

출력: 교체 가능한 어댑터가 만드는 타입 지정 Proposal 후보.

### 무엇을 보존하는가

- Git 관리 프롬프트. 후보는 Proposal 계약으로 저장합니다.
- 프롬프트 결과가 바로 정식 지식이 되지 않습니다. 모델 SDK나 자율 추출 파이프라인을 뜻하지 않습니다.
