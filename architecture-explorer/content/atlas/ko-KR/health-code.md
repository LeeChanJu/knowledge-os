run_doctor는 저장된 계보와 스키마·인덱스 등 무결성을 검사합니다. 정상 응답 여부만 보는 API 상태 확인과 다르며, 쓰기 교정은 수행하지 않습니다.

<!-- DEPTH -->

### 왜 이 책임이 필요한가

이력을 지우는 정규화 없이 위반을 감지합니다.

### 입력과 출력

입력: 기존 그래프, 마이그레이션 파일, 운영 저장소.

출력: 범위가 제한된 무결성 보고서.

### 무엇을 보존하는가

- 복구 상태를 소유하지 않습니다.
- 탐지와 정정을 구분합니다. F3에는 검사 범위·호환성 미해결 사례가 있습니다.

### 예시를 따라가 보기

메모 검색이 성공해도 연결이 빠졌거나 해시가 틀릴 수 있습니다. Doctor의 구조 검사와 사용자의 질문 답변 품질을 구별해야 합니다.

### 혼동하지 말아야 할 점

탐지와 정정을 구분합니다. F3에는 검사 범위·호환성 미해결 사례가 있습니다.
