저장소·LLM·MCP가 바뀌어도 여섯 계약 경계를 다시 정의하지 않습니다. 구현 선택보다 계보와 승인 규칙이 먼저입니다.

### 왜 이 책임이 필요한가

REST·MCP·저장 어댑터·UI와 독립적인 안정 경계를 정의합니다.

### 입력과 출력

입력: 안정 식별과 권한이 있는 제공자 관찰.

출력: 버전 근거와 커밋된 원본 실행 이력.

### 무엇을 보존하는가

- Source 계약 버전. 운영 데이터는 Neo4j에 있습니다.
- 제공자 재시도로 의미 상태가 중복되면 안 됩니다.

### 예시를 따라가 보기

메모의 제공자가 바뀌어도 원본 식별·근거·승인 경계를 다시 정의하지 않습니다. 실제 부족함이 측정될 때 계약과 설계 변경을 검토합니다.

### 혼동하지 말아야 할 점

제공자 재시도로 의미 상태가 중복되면 안 됩니다.
