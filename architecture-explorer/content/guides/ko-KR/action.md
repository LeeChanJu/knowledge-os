원본 시스템의 어댑터를 통해 무언가를 변경하려는 관리 대상 요청입니다.

## 이 단계에서 생기는 문제

변경을 제안할 권한과 승인하거나 실행할 권한은 다릅니다. 지식에 접근할 수 있다고 외부 기록을 변경할 권한까지 생겨서는 안 됩니다.

## 한 메모를 따라가 보기

Claude/GPT가 메모를 물으면 MCP가 정해진 읽기 요청을 전달합니다. 연결됐다는 이유로 임의 Cypher, 지식 승인, 외부 실행 권한을 얻지 않습니다.

## 개념과 구현을 구분하기

승인된 Action도 권한 있는 어댑터가 수행하기 전에는 미실행 상태입니다. 멱등성을 무시하는 외부 API에 정확히 한 번 실행을 보장하지 않습니다.

Action에는 정책·주체 스냅샷, 승인, 실행 전 점유, 실행 근거를 보존합니다.

## 구현이 지켜야 할 경계

- 직접 Cypher·수집·승인·Action 실행·외부 변경 도구는 없습니다. 관리 대상 요청을 제출할 수 있으므로 MCP 전체가 읽기 전용은 아닙니다.

## 입력·출력·데이터 책임

- 제한된 MCP 인자와 호스트 소유 작업공간·주체.
- 지식 서비스 결과 또는 관리 대상 요청 접수.
- 호스트 어댑터 설정만 소유하며 별도 지식 저장소는 없습니다.

## 비슷해 보이는 개념 비교

| 구분 | 답하는 질문 / 역할 | 주의할 경계 |
|---|---|---|
| 결정 | 무엇을 하기로 받아들였는가 | 근거와 판단 이력 |
| 실행 요청 | 원본에 어떤 변경을 요청하는가 | 별도 정책·승인·실행 권한 |

### 검토자가 지식 후보를 승인하면 Notion 변경도 자동으로 실행되나요?

아닙니다. 외부 변경은 승인된 구체적 요청과 정책, 인증된 실행 어댑터가 필요합니다. 실행 시도와 외부 성공 결과도 구분합니다.

### 코드나 테스트 파일이 존재한다는 것만으로 이 기능을 믿어도 될까요?

아닙니다. 아래 연결된 테스트의 실행 결과·리비전·환경·검증 범위를 확인해야 합니다. 열린 문제와 보류 범위를 제외하고 판단하며, 이 문서 탐색은 운영 테스트를 실행하지 않습니다.
