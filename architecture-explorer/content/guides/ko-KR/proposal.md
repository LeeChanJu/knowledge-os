정해진 검토 절차를 기다리는 지식 변경 후보입니다.

## 이 단계에서 생기는 문제

수정 초안과 승인된 수정은 다릅니다. AI의 제안이 조용히 정식 사실로 바뀌어서는 안 됩니다.

## 한 메모를 따라가 보기

검토자는 메모를 실제로 읽을 수 있어야 하며 후보와 근거를 비교합니다. MCP로 후보를 제출한 AI가 이 승인을 대신하지 않습니다.

## 개념과 구현을 구분하기

같은 내용의 재시도는 같은 수명주기 기록으로 연결됩니다. 근거는 해당 작업공간에 속하고 현재 권한으로 접근 가능해야 합니다.

제안 생성 시 내용 식별과 근거를 연결하고, 승인 또는 거절 결과를 변경 불가능한 기록으로 남깁니다.
