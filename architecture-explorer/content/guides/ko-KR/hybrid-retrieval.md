서로 보완하는 검색 신호를 결합해 유용한 근거를 찾는 방식입니다.

## 이 단계에서 생기는 문제

이름 찾아보기와 유사도 지도는 서로 다른 방식으로 도움이 됩니다. 질문마다 필요한 신호가 다르므로 한 가지 검색법이 언제나 최선인 것은 아닙니다.

## 한 메모를 따라가 보기

“Joule”라는 단어를 기억하면 정확한 단어 검색으로 후보를 찾습니다. 결과를 받았어도 인용한 메모가 실제 질문에 답하는지는 별도로 읽어야 합니다.

## 개념과 구현을 구분하기

벡터·전문·그래프 검색이 자동으로 하나로 합쳐지는 운영 파이프라인처럼 그리지 않습니다. 제공자 비활성과 평가 한계도 표시합니다.

혼합 검색은 키워드와 의미 검색 결과를 결합합니다. 그래프 탐색은 별도로 제공되는 계약 경로입니다.

## 구현이 지켜야 할 경계

이 문서에서 참조하는 **키워드·혼합 검색 (Keyword / Hybrid)**의 구현 책임입니다. 개념이나 학습 단계 자체를 별도 서비스로 뜻하는 것은 아닙니다.

- 결합 과정에서 권한 요구를 버릴 수 없습니다.

## 입력·출력·데이터 책임

이 문서에서 참조하는 **키워드·혼합 검색 (Keyword / Hybrid)**의 구현 책임입니다. 개념이나 학습 단계 자체를 별도 서비스로 뜻하는 것은 아닙니다.

입력: 검색어, 모드, 접근 맥락, 선택적인 벡터·모델·버전.

출력: 순위가 있는 근거와 추적 ID.

보유 데이터: 추가 인덱스 서비스가 없습니다.

## 비슷해 보이는 개념 비교

| 구분 | 답하는 질문 / 역할 | 주의할 경계 |

### 벡터 인덱스가 있으면 모든 메모의 의미 검색이 이미 가능한가요?

아닙니다. 호환되는 모델과 임베딩 자료, 검증된 제공자 선택이 별도로 필요합니다. 현재 운영 자료 채움과 제공자 보류 범위를 확인해야 합니다.

### 코드나 테스트 파일이 존재한다는 것만으로 이 기능을 믿어도 될까요?

아닙니다. 아래 연결된 테스트의 실행 결과·리비전·환경·검증 범위를 확인해야 합니다. 열린 문제와 보류 범위를 제외하고 판단하며, 이 문서 탐색은 운영 테스트를 실행하지 않습니다.
