범위가 정해진 지식·근거 작업을 제공하는 서비스 인터페이스입니다.

## 이 단계에서 생기는 문제

정해진 신청서가 있는 창구처럼 저장소에 무제한 접근하는 대신 특정 작업을 제공합니다. 사용자는 그래프 저장 방식의 내부에 의존하지 않고 지식을 사용할 수 있습니다.

## 한 메모를 따라가 보기

메모의 제공자가 바뀌어도 원본 식별·근거·승인 경계를 다시 정의하지 않습니다. 실제 부족함이 측정될 때 계약과 설계 변경을 검토합니다.

## 개념과 구현을 구분하기

읽기에는 작업공간과 원본 기반 권한이 적용됩니다. 이 문서 사이트는 해당 엔드포인트를 호출하지 않습니다.

REST가 안정 계약의 작업을 노출하고 어댑터가 인증된 접근 맥락을 구성합니다.

## 구현이 지켜야 할 경계

- 순위와 벡터 검색이 근거 권한을 우회하지 않습니다.

## 입력·출력·데이터 책임

- 검색어, 의미 검색의 정확한 모델·버전, 인증 접근.
- 제한된 순위 맥락, 기능, 추적, 평가 근거.
- Retrieval 계약 버전.

## 비슷해 보이는 개념 비교

| 구분 | 답하는 질문 / 역할 | 주의할 경계 |
|---|---|---|
| 어댑터 | 외부 요청을 정해진 계약으로 전달 | MCP·REST는 교체 가능 |
| 안정 계약 | 무엇을 읽고 제안·실행할 수 있는가 | 계보·권한·승인 경계 유지 |

### MCP에 연결한 AI가 임의 Cypher나 승인 권한을 얻는가요?

아닙니다. 어댑터는 정해진 요청만 전달합니다. 직접 DB 탐색·지식 승인·외부 실행은 연결 자체로 허용되지 않습니다.

### 코드나 테스트 파일이 존재한다는 것만으로 이 기능을 믿어도 될까요?

아닙니다. 아래 연결된 테스트의 실행 결과·리비전·환경·검증 범위를 확인해야 합니다. 열린 문제와 보류 범위를 제외하고 판단하며, 이 문서 탐색은 운영 테스트를 실행하지 않습니다.
