AI 호스트가 공개된 도구를 호출하는 데 사용하는 어댑터 프로토콜입니다.

## 이 단계에서 생기는 문제

어시스턴트와 도구를 잇는 연결 장치이지 데이터베이스의 규칙 자체는 아닙니다. MCP를 교체 가능하게 두면 특정 AI 프로토콜이 지식의 핵심 의미를 결정하지 않게 됩니다.

## 한 메모를 따라가 보기

Claude/GPT가 메모를 물으면 MCP가 정해진 읽기 요청을 전달합니다. 연결됐다는 이유로 임의 Cypher, 지식 승인, 외부 실행 권한을 얻지 않습니다.

## 개념과 구현을 구분하기

어댑터는 관리 절차를 따르는 요청을 제출할 수 있지만 Action을 승인하거나 실행할 수는 없습니다. 임의의 Cypher도 제공하지 않습니다.

stdio 어댑터는 호스트가 정한 작업공간과 주체로 서비스 계약을 제공합니다.

## 구현이 지켜야 할 경계

- 직접 Cypher·수집·승인·Action 실행·외부 변경 도구는 없습니다. 관리 대상 요청을 제출할 수 있으므로 MCP 전체가 읽기 전용은 아닙니다.

## 입력·출력·데이터 책임

- 제한된 MCP 인자와 호스트 소유 작업공간·주체.
- 지식 서비스 결과 또는 관리 대상 요청 접수.
- 호스트 어댑터 설정만 소유하며 별도 지식 저장소는 없습니다.

## 비슷해 보이는 개념 비교

| 구분 | 답하는 질문 / 역할 | 주의할 경계 |
|---|---|---|
| 어댑터 | 외부 요청을 정해진 계약으로 전달 | MCP·REST는 교체 가능 |
| 안정 계약 | 무엇을 읽고 제안·실행할 수 있는가 | 계보·권한·승인 경계 유지 |

### MCP에 연결한 AI가 임의 Cypher나 승인 권한을 얻는가요?

아닙니다. 어댑터는 정해진 요청만 전달합니다. 직접 DB 탐색·지식 승인·외부 실행은 연결 자체로 허용되지 않습니다.

### 코드나 테스트 파일이 존재한다는 것만으로 이 기능을 믿어도 될까요?

아닙니다. 아래 연결된 테스트의 실행 결과·리비전·환경·검증 범위를 확인해야 합니다. 열린 문제와 보류 범위를 제외하고 판단하며, 이 문서 탐색은 운영 테스트를 실행하지 않습니다.
