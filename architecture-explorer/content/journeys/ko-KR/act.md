## 결정과 실제 변경은 같은가요?

```diagram
“이렇게 하기로 했다” → 결정 기록
“원본에 반영해달라” → 별도 변경 요청
요청만으로 실행되지 않음
```

무엇을 하기로 결정한 것과 실제 외부 시스템을 바꾸는 것은 다릅니다. 실행 요청에는 대상과 수행하려는 작업을 명시해야 합니다. 연결 창구를 통해 요청했다고 승인 권한이 생기지는 않습니다.

<!-- stage:policy -->
## 어디까지 바꿔도 되나요?

```diagram
요청한 작업과 대상
↓ 등록된 허용 범위·정책 확인
범위를 벗어나면 실행하지 않음
```

현재는 제한된 Notion 경로가 있으며 모든 시스템을 쓰는 범용 실행자는 아닙니다. 읽기 권한이 있어도 쓰기 권한이 자동으로 생기지 않습니다. 예시는 학습용이며 이 화면은 실제 변경을 요청하지 않습니다.

<!-- stage:approve -->
## 요청한 AI가 스스로 승인해도 될까요?

```diagram
AI의 변경 요청
↓ 별도 사람의 검토·승인
승인된 범위만 실행 후보가 됨
```

승인은 요청과 분리된 권한 있는 사람의 판단입니다. 현재 에이전트 연결 창구는 승인하거나 실행하지 않습니다. 요청자의 뜻과 실제로 허용한 변경 범위를 구분해서 남깁니다.

<!-- stage:execute -->
## 누가 원본을 바꾸나요?

```diagram
승인된 요청
↓ 별도 권한을 가진 실행자
허용된 Notion 위치 → 결과 확인
```

외부 쓰기는 별도 권한과 정책을 가진 실행자가 수행합니다. 실행을 시도했다는 사실과 원본에서 성공했다는 사실은 다릅니다. 중복 실행 방지와 모호한 결과의 처리에도 검증 범위와 열린 항목이 있습니다.

<!-- stage:record -->
## 실행 후에는 무엇을 확인할까요?

```diagram
실행 결과 기록
↓ 원본을 다시 읽어 근거 연결
성공·실패·모호한 결과를 구별
```

실행 결과와 원본에서 관찰한 상태를 연결해 나중에 확인할 수 있게 합니다. 되돌리기 역시 별도 승인된 작업일 수 있으며 모든 실패를 자동 복구한다고 가정하지 않습니다. 이 문서 사이트는 읽기 전용이며 실제 실행을 하지 않습니다.
